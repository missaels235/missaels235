## About

I am a **Mobile Security Researcher and Reverse Engineer** focused on **iOS application security, runtime analysis, dynamic instrumentation, and jailbreak environments**.

My work centers on understanding what happens beneath the user interface: authentication flows, trust boundaries, application entitlements, runtime protections, network behavior, and client-side security assumptions.

I build small, purpose-driven tools for **inspection, tracing, validation, and reproducible security research** using **Frida, Python, JavaScript, Swift, LLDB, and native iOS tooling**.

> I prefer runtime evidence over assumptions and reproducible results over hype.

---

## Focus Areas

- **iOS Security** — application internals, entitlements, sandbox behavior, Keychain, lifecycle analysis
- **Reverse Engineering** — Objective-C runtime inspection, native analysis, control-flow investigation
- **Dynamic Instrumentation** — Frida agents, tracing, method interception, behavioral logging
- **Application Security** — authentication flows, trust boundaries, anti-debugging, anti-tampering
- **Network Security** — API inspection, TLS behavior, certificate pinning, traffic analysis
- **Vulnerability Research** — attack-surface mapping, root-cause analysis, proof-of-concept validation
